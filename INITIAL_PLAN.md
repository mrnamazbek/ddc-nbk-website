# INITIAL_PLAN.md (Первоначальный план проекта — Черновик)

Этот документ подготовлен в рамках **Phase 0** проекта по созданию высококлассного веб-сайта для дочерней организации Национального Банка Казахстана — **DDC**.

---

## 1. Предложенная структура сайта (Pages & Sections)

Сайт будет состоять из следующих страниц:
1. **Главная страница (`/`)**:
   - Кинематографичный первый экран (Hero) с интерактивным 3D-фоном.
   - Секция ключевых показателей эффективности (Stats Counter) — объем активов, количество транзакций, годы стабильности.
   - Сетка ключевых услуг (Services Grid) с эффектом стеклянного наведения.
   - Блок «О компании» (About Teaser) с премиальным параллаксом.
   - Панель инноваций (Digital Solutions Showcase) — демонстрация технологических платформ.
   - Блок комплаенса и безопасности (Security & Trust) с подтверждением стандартов.
   - Пресс-центр (News Teaser) — последние важные события.
   - Финальный призыв к действию (CTA Section) с магнитной кнопкой связи.
2. **О компании (`/about`)**:
   - Подробная миссия и государственные задачи организации.
   - История в виде интерактивного таймлайна развития.
   - Руководство и структура управления (команда с премиум-эффектами).
3. **Услуги (`/services`)**:
   - Полный каталог услуг для государственных и финансовых институтов Казахстана.
   - Подробные карточки с описанием регламентов и преимуществ.
4. **Цифровые технологии (`/digital`)**:
   - Презентация технологического стека и проектов национального масштаба (например, интеграция с Цифровым Тенге).
   - Интерактивные схемы архитектуры решений.
5. **Безопасность и комплаенс (`/security`)**:
   - Государственные стандарты защиты данных, лицензии, аудиты.
6. **Пресс-центр (`/news`)**:
   - Лента новостей с категориями (Пресс-релизы, Аналитика, События).
   - Шаблон детальной статьи новостей.
7. **Карьера (`/careers`)**:
   - Вакансии с фильтрами по направлениям (Data Engineer, Python, SQL Developer).
   - Преимущества работы в DDC, форма для отправки резюме.
8. **Контакты (`/contact`)**:
   - Интерактивная векторная карта расположения офисов (Алматы, Астана).
   - Форма обратной связи с валидацией.
9. **FAQ (`/faq`)**:
   - Интерактивные аккордеоны с ответами на частые вопросы.
10. **404 (`Custom 404`)**:
    - Страница ошибки в фирменном строгом стиле с быстрым возвратом на главную.

## 2. Предложенный стек технологий с обоснованием

- **Фреймворк**: Next.js 14+ (App Router, Strict TypeScript)
  *Обоснование*: Лучший фреймворк для SEO, быстрой загрузки страниц (благодаря Server Components) и бесшовной интеграции с Vercel.
- **Стилизация**: Tailwind CSS + CSS-переменные
  *Обоснование*: Гарантирует быстродействие, легкое внедрение дизайн-системы и адаптивность.
- **Анимации**: Framer Motion + GSAP (ScrollTrigger)
  *Обоснование*: GSAP идеально подходит для плавных скролл-анимаций (скраббинг, параллакс), а Framer Motion — для легких анимаций компонентов и переходов между страницами.
- **Плавный скролл**: Lenis
  *Обоснование*: Обеспечивает премиальный «дорогой» опыт прокрутки на всех операционных системах и браузерах.
- **3D-графика**: Three.js + React Three Fiber + @react-three/drei
  *Обоснование*: Позволяет интегрировать интерактивные шейдеры и 3D-сцены непосредственно в React-компоненты.
- **Шрифты**: next/font (Cormorant Garamond — для статусных заголовков, Inter — для разборчивого интерфейсного текста).
- **Валидация форм**: React Hook Form + Zod.
- **Деплой**: Vercel (интеграция с GitHub).

## 3. Стратегия анимации (Motion Language)

1. **Первое появление (Entrance)**:
   - Заголовки на первом экране плавно раскрываются снизу вверх со сдвигом (stagger-эффект) с использованием `clip-path` за 0.8 секунд.
2. **Скролл-эффекты (Scroll-driven)**:
   - Элементы интерфейса проявляются по мере прокрутки (fade-in-up) с мягким затуханием.
   - Изображения в блоках «О нас» имеют тонкий параллакс-эффект движения в противоположную от скролла сторону.
3. **Наведение (Hover)**:
   - Кнопки имеют эффект притяжения к курсору (magnetic effect).
   - Стеклянные карточки услуг (Glassmorphism) при наведении плавно увеличиваются на 2%, их золотая рамка начинает мягко светиться (`glow`), а фон становится чуть более плотным.
4. **3D-интерактивность**:
   - Курсор мыши слегка деформирует и притягивает частицы на заднем плане Hero-экрана, создавая эффект отзывчивой «живой» среды.
   - Карточки услуг имеют эффект наклона в сторону курсора (3D tilt) до 8 градусов.

## 4. Правила использования цвета (Color Palette Rules)

Дизайн должен быть строгим, авторитетным и премиальным:
- **Доминирующий цвет (60%)**: Глубокий темно-зеленый (Forest Green — `#1A3D2B`) и черный/темно-серый уголь (`#0A0A0A`, `#1C1C1E`) для создания авторитетной ночной атмосферы.
- **Вторичный цвет (30%)**: Чистый белый (`#FFFFFF`) и теплый молочный (`#F5F5F0`) для светлых секций и читаемости текстов.
- **Цвет премиум-акцента (10%)**: Чистое золото (`#C9A84C`) и его оттенки (`#E8C87A`, `#8B7035`) для выделения ключевых заголовков, цифр статистики, активных рамок и кнопок.
- **Стеклянный эффект (Glassmorphism)**: Использование полупрозрачного белого/золотого фона (`rgba(255,255,255,0.06)`) с сильным размытием заднего плана (`blur(24px)`) для создания ощущения премиальной глубины.

## 5. Первоначальный перечень компонентов

- **Макет (Layout)**: `Header` (прозрачный при прокрутке, с локализацией KZ/RU/EN), `Footer` (премиальный многоколоночный), `MobileNav` (полноэкранный оверлей).
- **Секции (Sections)**: `Hero`, `StatsGrid`, `ServicesList`, `ParallaxAbout`, `DigitalShowcase`, `SecurityShield`, `NewsGrid`, `ContactForm`.
- **UI-элементы**: `Button` (премиальные кнопки с микро-анимацией), `GlassCard` (карточка с эффектом стекла), `Badge` (статусные метки), `Accordion` (вопросы и ответы).
- **Интерактивные Motion-компоненты**: `ScrollReveal` (плавное появление), `MagneticWrapper` (притяжение к мыши), `CursorTrail` (мягкий след курсора).
- **3D-компоненты**: `HeroScene` (сцена R3F), `ParticleField` (облако частиц), `FloatingMesh` (парящие геометрические тела).

## 6. Бюджет производительности (Performance Budget)

- **Lighthouse Score**:
  - Performance: >90 на десктопе, >75 на мобильных устройствах.
  - Accessibility: >95 (полная поддержка читалок, контрастность).
  - Best Practices: 100%.
  - SEO: 100%.
- **Вес страницы**: Первоначальная загрузка домашней страницы не должна превышать **2.0 MB** (все тяжелые 3D ресурсы загружаются асинхронно после рендеринга основного контента).
- **Плавность интерфейса**: Стабильные **60 FPS** при скролле и взаимодействиях на стандартных офисных компьютерах. На старых смартфонах 3D отключается, гарантируя плавность.
