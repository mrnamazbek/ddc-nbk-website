# DESIGN_SYSTEM_2026 — Спецификация дизайн-системы DDC / NBK (Forest Green & Gold)

---

## 1. Цветовая палитра (Color Palette)

Новый брендбук DDC / NBK базируется на благородном сочетании лесного зеленого, премиального золота и контрастных темных оттенков, передающих стабильность государственной финансовой системы Казахстана.

### Основные цвета (Primary)
*   `--color-forest`: `#1A3D2B` — Глубокий лесной зеленый (символизирует стабильность, доверие, природу Казахстана, авторитет).
*   `--color-forest-mid`: `#2D6A4F` — Средне-зеленый (используется для интерактивных состояний, ховеров кнопок).
*   `--color-forest-light`: `#52B788` — Акцентный светло-зеленый (символизирует технологический рост, успех, позитивные финансовые тренды).

### Золотые акценты (Prestige Gold)
*   `--color-gold`: `#C9A84C` — Премиальное золото (символизирует богатство, престиж, суверенитет, национальное наследие).
*   `--color-gold-light`: `#E8C87A` — Светлое золото (используется для ховеров, яркой подсветки, выделения текста).
*   `--color-gold-dark`: `#8B7035` — Глубокое темное золото (тени, границы, рефракция).

### Нейтральные тона (Neutrals)
*   `--color-black`: `#0A0A0A` — Насыщенный угольный черный (цвет глубокого фона сайта).
*   `--color-charcoal`: `#1C1C1E` — Темно-серый (цвет карточек, боковых панелей, элементов интерфейса).
*   `--color-white`: `#FFFFFF` — Абсолютно белый.
*   `--color-offwhite`: `#F5F5F0` — Мягкий белый с теплым оттенком (основной цвет текстов в светлой теме / акцентные текстовые блоки).

### Дополнительный акцент (Accent)
*   `--color-yellow`: `#F5C518` — Яркий золотисто-желтый (используется для критических CTA-кнопок и предупреждений).

### Система жидкого стекла (Apple Liquid Glass Tokens)
*   `--glass-white-bg`: `rgba(255, 255, 255, 0.05)`
*   `--glass-white-border`: `rgba(255, 255, 255, 0.08)`
*   `--glass-dark-bg`: `rgba(0, 0, 0, 0.35)`
*   `--glass-dark-border`: `rgba(255, 255, 255, 0.04)`
*   `--glass-gold-tint`: `rgba(201, 168, 76, 0.06)`
*   `--glass-blur`: `blur(32px) saturate(210%) brightness(1.05)`
*   `--glass-radius`: `20px`

## 2. Типографика (Typography)

Плавная, адаптивная система шрифтов (Fluid Typography), масштабируемая с использованием CSS `clamp()`.

*   **Display Font (Эмоциональный)**: `"Cormorant Garamond"` (свободно импортируемый из Google Fonts) — утонченная классическая антиква, передающая государственную значимость и историю. Используется исключительно для крупных заголовков Hero-секции и заголовков ключевых разделов.
*   **Heading & UI Font (Интерфейсный)**: `"Inter"` — современный геометрический гротеск с превосходной читаемостью. Используется для подзаголовков, навигации, карточек и кнопок.
*   **Data Font (Цифровой)**: `"JetBrains Mono"` — моноширинный шрифт, обеспечивающий идеальное выравнивание цифр в таблицах курсов валют, базовых ставок и статистических метрик.

### Шрифтовые размеры:
*   `--hero`: `clamp(3.5rem, 8vw, 8rem)` — Главные заголовки Hero.
*   `--h1`: `clamp(2.2rem, 4.5vw, 4.5rem)` — Заголовки разделов первого уровня.
*   `--h2`: `clamp(1.8rem, 3.5vw, 3rem)` — Заголовки второго уровня.
*   `--large`: `clamp(1.15rem, 1.8vw, 1.4rem)` — Лид-текст, подзаголовки.
*   `--body`: `clamp(0.95rem, 1.3vw, 1.05rem)` — Основной читаемый текст.
*   `--small`: `clamp(0.8rem, 1vw, 0.9rem)` — Подписи, карточки, элементы форм.

## 3. Физика переходов и анимация (Motion & Physics)

Для создания ощущения «живого» премиального интерфейса в 2026 году все микро-взаимодействия подчиняются строгим физическим законам (без линейных переходов).

*   **Тайминг-функции (Easing)**:
    *   `--ease-expo`: `cubic-bezier(0.16, 1, 0.3, 1)` — Быстрый старт и мягкое, длительное затухание (идеально для раскрытия карточек, меню, появления страниц).
    *   `--ease-spring`: `cubic-bezier(0.34, 1.56, 0.64, 1)` — Эластичный отскок (используется для ховер-эффектов кнопок и 3D-наклона).
    *   `--ease-smooth`: `cubic-bezier(0.4, 0, 0.2, 1)` — Стандартный мягкий переход для элементов интерфейса.
*   **Временные интервалы (Durations)**:
    *   `--fast`: `150ms` (микро-эффекты: наведение на ссылки, движение курсора).
    *   `--base`: `300ms` (стандартный ховер на карточки, переключатели).
    *   `--slow`: `600ms` (плавное появление блоков при скролле).
    *   `--cinematic`: `1200ms` (3D-анимации, появление Hero-секции).
