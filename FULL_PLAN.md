# FULL_PLAN.md (Развернутый план проекта)

Этот документ представляет собой расширенную версию `INITIAL_PLAN.md`, обогащенную реальными результатами исследований (**Phase 1**), проведенных с помощью поисковых систем Antigravity. План служит окончательным руководством для разработки премиального веб-сайта **DDC** (Digital Development Center), дочерней организации Национального Банка Казахстана.

---

## 1. Результаты исследований (Research Findings)

### 1A. Премиальный банковский дизайн и UX (2025–2026)
Современные стандарты для премиальных финансовых брендов (таких как Revolut, Morgan Stanley, BlackRock и Центральные банки мира) базируются на следующих принципах:
- **«Стратегическая простота» (Strategic Simplicity)**: Использование обильного свободного пространства (white space), сдержанной палитры и строгой сетки.
- **Темная технологичная эстетика**: Использование глубоких темных оттенков (угольный, темно-зеленый, серый) как маркера высокого статуса и премиальности бренда.
- **Интерактивная визуализация данных**: Сложные графики заменяются на интерактивные, интуитивно понятные предсказательные диаграммы и 3D-модели активов.
- **Производительность как синоним безопасности**: Пользователь подсознательно ассоциирует скорость работы интерфейса с надежностью защиты его данных. Оптимизация Core Web Vitals имеет критическое значение.

### 1B. Интеграция 3D-графики (WebGL / Three.js) в финансах
- **Абстрактный брендинг**: 3D используется для создания премиального первого экрана (Hero section) с помощью абстрактной геометрии, парящих стеклянных карт или частиц, символизирующих потоки капитала и блокчейн-данных.
- **Технические решения**: Для React-приложений стандартом является связка **React Three Fiber (R3F)** и **@react-three/drei**.
- **Оптимизация производительности**:
  - Использование `InstancedMesh` для отрисовки облаков частиц (сокращает вызовы отрисовки — Draw Calls).
  - Ленивая загрузка 3D-компонентов (`next/dynamic` с SSR: false).
  - Адаптивное отключение 3D на экранах менее 768px и замена его на плавный CSS-градиент.

### 1C. Национальная цифровая идентичность Казахстана (Saka Style & Human-Centric)
- **Сакский звериный стиль (Saka Style)**: Новый стандарт дизайна Национального Банка РК сочетает историческое наследие (артефакты сакской эпохи) и пульсирующие футуристичные линии защиты. Мы внедрим этот подход в веб-дизайн, используя тонкие геометрические линии и анимации, отсылающие к сакскому искусству и ландшафтам Казахстана.
- **Человекоцентричность (Human-Centered Design)**: Следуя новому Цифровому Кодексу Казахстана, сайт должен обеспечивать максимальную доступность (WCAG 2.1 AA), интуитивную структуру и поддержку трех основных языков (Казахский, Русский, Английский).

## 2. Архитектура и структура сайта (Information Architecture)

Сайт будет включать следующие разделы:
- `/` (Главная) — cinematic hero с 3D, Stats counter, интерактивный каталог услуг с эффектом стекла, параллакс-история, блок цифровых платформ, безопасность, новости и CTA.
- `/about` (О компании) — миссия, ценности, руководство DDC и интерактивный таймлайн.
- `/services` (Услуги) — детальный каталог государственных и коммерческих финансовых решений.
- `/digital` (Цифровые технологии) — проекты национального значения (Цифровой Тенге, открытый банкинг).
- `/security` (Безопасность и комплаенс) — стандарты шифрования, соответствие регуляторным требованиям.
- `/news` (Пресс-центр) — новости, аналитические статьи (CMS на основе MDX).
- `/careers` (Карьера) — описание команды, вакансии и форма обратной связи.
- `/contact` (Контакты) — интерактивная SVG-карта, адреса, формы связи.
- `/faq` (Вопросы и ответы) — структурированный аккордеон ответов.
- `404` — стилизованная страница ошибки.

## 3. Дизайн-система и цветовые константы (Design Tokens)

Мы реализуем строгую премиальную палитру в `styles/tokens.css`:
- `Primary Brand`: Deep Forest Green (`#1A3D2B`) — цвет стабильности и государственного авторитета.
- `Secondary Action`: Mid Forest (`#2D6A4F`) и Light Accent (`#52B788`).
- `Premium Accent`: Rich Gold (`#C9A84C`) и Light Gold (`#E8C87A`) — цвет премиального статуса Национального Банка.
- `Neutral Dark`: Near Black (`#0A0A0A`), Charcoal (`#1C1C1E`) — базовый фон.
- `Neutral Light`: Pure White (`#FFFFFF`), Warm White (`#F5F5F0`) — для контрастных секций и текстов.
- `Glass Effect (Glassmorphism)`: Полупрозрачные подложки `rgba(255,255,255,0.06)` с сильным размытием заднего плана `blur(24px)` и золотистой рамкой `rgba(201,168,76,0.15)`.

## 4. Развернутый план разработки по этапам (Zero to Hero)

### Шаг 1. Создание Git-репозитория и инициализация Next.js
1. Создание репозитория `ddc-nbk-website` на GitHub с помощью PAT-токена.
2. Локальная инициализация проекта: `npx create-next-app@latest . --typescript --tailwind --app`.
3. Установка библиотек: `three`, `@types/three`, `@react-three/fiber`, `@react-three/drei`, `gsap`, `@studio-freight/lenis`, `framer-motion`, `lucide-react`, `react-hook-form`, `zod`.
4. Настройка ESLint, Prettier, `.gitignore`.

### Шаг 2. Создание дизайн-системы и базовых компонентов
1. Описание `tokens.css` и подключение шрифтов Cormorant Garamond и Inter через `next/font`.
2. Создание UI-примитивов: `Button`, `Card`, `GlassCard`, `Badge`.
3. Создание анимационных врапперов: `ScrollReveal`, `MagneticWrapper`.

### Шаг 3. Реализация Макетной системы (Layout)
1. Разработка `Header` с эффектом прозрачности при скролле, выпадающим меню, переключателем языков и кнопкой обратной связи.
2. Разработка `Footer` с многоколоночной структурой и золотой разделительной линией.
3. Интеграция `Lenis` для плавного скролла.

### Шаг 4. Разработка Hero-секции и R3F Canvas
1. Подключение `<Canvas>` с поддержкой Suspense.
2. Создание сцены Three.js: вращающиеся абстрактные геометрические фигуры Сакского стиля со стеклянной текстурой.
3. Создание облака частиц (золотые и изумрудные), реагирующих на сдвиг мыши.
4. Анимация заголовков Cormorant Garamond с эффектом посимвольного появления.

### Шаг 5. Поэтапная верстка разделов главной страницы
1. **Stats**: 4 анимированных счетчика (GSAP `onUpdate`) на стеклянных подложках.
2. **Services Grid**: 6 карточек с 3D Tilt эффектом наведения.
3. **About**: Раздел с перекрывающимися параллакс-изображениями (природа и архитектура Казахстана).
4. **Digital Showcase**: Презентация проекта Цифрового Тенге с анимированным макетом смартфона/карты.
5. **Security**: Секция с анимированным SVG-щитом и государственными лицензиями.
6. **News**: Сетка новостей с зумом изображений при наведении.
7. **CTA**: Полноэкранный баннер с градиентным золотисто-зеленым свечением и магнитной кнопкой.

### Шаг 6. Разработка внутренних страниц
1. Создание всех остальных страниц (`/about`, `/services`, `/digital`, `/security`, `/news`, `/careers`, `/contact`, `/faq`).
2. Добавление плавного эффекта смены страниц (Wipe Transition).

### Шаг 7. QA, Оптимизация и Деплой
1. Lighthouse-аудит (Performance >90, Accessibility >95).
2. Ленивая загрузка Three.js, сжатие текстур и WebP-изображений.
3. Настройка GitHub Actions (`ci.yml`) для линтинга и автодеплоя на Vercel.
4. Финальный тег релиза `v1.0.0-release`.
