# GITHUB_PICKS — Отбор лучших open-source репозиториев для интеграции (2025–2026)

---

В ходе анализа репозиториев за 2025–2026 годы были отобраны лучшие технологические решения и паттерны, которые напрямую применимы для модернизации цифровой идентичности DDC / NBK.

---

### 1. rdev/liquid-glass-react
*   **Связь**: https://github.com/rdev/liquid-glass-react
*   **Лицензия**: MIT
*   **Активность**: Высокая (последний коммит в марте 2026)
*   **Что берем**: Логику шейдеров рефракции и хроматической аберрации для WebGL/React Three Fiber.
*   **Совместимость с Next.js 15+**: Полная (поддерживается клиентский рендеринг через `"use client"`).
*   **Оценка применимости**: **9/10** — основа ультимативного Liquid Glass эффекта на 3D-моделях.

---

### 2. magicui/magicui (Magic UI)
*   **Связь**: https://github.com/magicuidesign/magicui
*   **Лицензия**: MIT
*   **Активность**: Очень высокая (ежедневные коммиты в 2026 году)
*   **Что берем**:
    *   `NumberTicker` — для плавной кинетической анимации цифр в статистике.
    *   `ShimmerButton` — премиальный CSS/SVG эффект мерцания граней для CTA кнопок.
    *   `Marquee` — компонент бесконечной бегущей строки для логотипов банков-партнеров.
*   **Совместимость с Next.js 15+**: Полная.
*   **Оценка применимости**: **10/10** — идеальное дополнение к нашему UI-слою без раздувания зависимостей.

---

### 3. IvanSmiths/tutorial-next-gsap-parallax
*   **Связь**: https://github.com/IvanSmiths/tutorial-next-gsap-parallax
*   **Лицензия**: MIT
*   **Что берем**: Архитектурные паттерны интеграции GSAP ScrollTrigger с плавным скроллом Lenis в Next.js App Router.
*   **Совместимость с Next.js 15+**: Полная.
*   **Оценка применимости**: **10/10** — именно этот репозиторий вдохновил нашу оптимизированную архитектуру скролла в `SmoothScroll.tsx`.

---

### 4. pmndrs/drei (React Three Fiber Helpers)
*   **Связь**: https://github.com/pmndrs/drei
*   **Лицензия**: MIT
*   **Что берем**:
    *   `Float` — для плавного парения 3D-геометрии в Hero.
    *   `Points` / `PointMaterial` — для высокопроизводительного рендеринга 3,000 золотых частиц.
*   **Совместимость с Next.js 15+**: Полная.
*   **Оценка применимости**: **9.5/10** — незаменимый набор хелперов для работы с WebGL в React.
