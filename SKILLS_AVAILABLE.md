# Доступные навыки Anthropic и их применение

В данном документе перечислены навыки, клонированные в директорию `.claude/skills/skills`, и определено, какие из них будут использоваться на различных этапах проекта.

## 1. Список доступных навыков

| Название навыка | Описание и сфера применения |
| :--- | :--- |
| **frontend-design** | Создание качественного, продакшн-уровневого фронтенд-дизайна. Избегает шаблонных решений AI (AI slop). |
| **canvas-design** | Разработка визуальных композиций и графики с использованием холста (Canvas). |
| **webapp-testing** | Автоматизированное тестирование веб-приложений с помощью Playwright. |
| **slack-gif-creator** | Создание анимированных GIF, оптимизированных под веб/интерфейсы. |
| **theme-factory** | Проектирование цветовых тем и дизайн-токенов. |
| **web-artifacts-builder** | Разработка интерактивных компонентов для веб-артефактов. |
| **doc-coauthoring** | Создание структурированных технических и проектных документов. |
| **skill-creator** | Разработка новых многоразовых навыков. |

---

## 2. Карта применения навыков по фазам проекта

### Фаза 2 — Инвентаризация активов
- **Используемый навык**: `doc-coauthoring` / `frontend-design`.
- **Цель**: Структурированное и точное описание всех графических, видео и текстовых ресурсов.

### Фаза 3 — Раскадровка видео и GSAP-скролл
- **Используемый навык**: `canvas-design` / `frontend-design`.
- **Цель**: Оптимальный рендеринг кадров видео на 2D Canvas с плавным GSAP ScrollTrigger управлением.

### Фазы 5 и 6 — Система жидкого стекла и техники дизайна
- **Используемый навык**: `frontend-design` / `theme-factory`.
- **Цель**: Внедрение CSS-классов `.liquid-glass`, `.liquid-glass-strong`, шрифтовой пары Instrument Serif + Barlow, кастомных оверлеев и иерархии прозрачности.

### Фаза 7 — Интеграция компонентов 21st.dev
- **Используемый навык**: `frontend-design`.
- **Цель**: Выбор, адаптация и рестайлинг премиальных интерфейсных блоков под токенизацию NBK.
