# DESIGN_SYSTEM.md (Дизайн-система DDC)

Этот документ содержит описание дизайн-системы веб-сайта дочерней организации Национального Банка Казахстана — **DDC** (Digital Development Center). Система разработана для создания ощущения государственного статуса, премиальности, безупречной безопасности и технологичности.

Все параметры дизайн-системы реализованы в виде CSS-переменных в файле `styles/tokens.css`.

---

## 1. Цветовая палитра (Color Rules)

Мы используем жестко дисциплинированную цветовую схему, которая сочетает доверие к государственному банку с современным высокотехнологичным финтех-обликом.

| Категория | Имя токена | Значение | Описание и Правило использования |
| :--- | :--- | :--- | :--- |
| **Primary Brand** | `--color-forest` | `#1A3D2B` | Глубокий темно-зеленый (лесной). Базовый цвет авторитета и стабильности. Занимает не менее 60% площади бренда. |
| **Secondary Brand** | `--color-forest-mid` | `#2D6A4F` | Средне-зеленый. Используется для акцентных подложек и кнопок второго уровня. |
| **Light Accent** | `--color-forest-light`| `#52B788` | Светло-зеленый. Метки успешного выполнения задач, статусы активности. |
| **Premium Accent** | `--color-gold` | `#C9A84C` | Роскошное благородное золото. Используется экономно (около 10% площади) для важнейших акцентов, цифр и активных элементов. |
| **Premium Hover** | `--color-gold-light` | `#E8C87A` | Светлое золото для состояний наведения (hover) золотых кнопок и рамок. |
| **Base Background** | `--color-black` | `#0A0A0A` | Глубокий иссиня-черный. Основной цвет фона страниц для создания эффекта премиальной ночной темы. |
| **Section & Cards** | `--color-charcoal` | `#1C1C1E` | Угольный серый. Используется для выделения отдельных карточек и контентных секций. |
| **Text Primary** | `--color-white` | `#FFFFFF` | Чистый белый для контрастных заголовоков. |
| **Text Secondary** | `--color-gray-light` | `#AEAEB2` | Спокойный светло-серый для снижения контраста длинных абзацев текста. |

### Эффект матового стекла (Glassmorphism)
Используется для создания ощущения глубины, прозрачности госструктуры и технологичности.
- **Фон**: `rgba(255, 255, 255, 0.04)` (или золотистый `rgba(201, 168, 76, 0.02)`)
- **Граница**: `rgba(255, 255, 255, 0.08)` (или акцентная золотая `rgba(201, 168, 76, 0.15)`)
- **Размытие**: `backdrop-filter: blur(24px) saturate(180%)`

## 2. Типографика (Typography Rules)

Мы используем три шрифта для четкого разделения ролей контента:
1. **Cormorant Garamond (Display)** — элегантная, премиальная антиква от Google.
   - *Где используется*: Главные заголовки (H1) на первом экране, названия ключевых разделов.
   - *Роль*: Создает благородное, солидное академическое ощущение вековой финансовой надежности.
2. **Inter (Interface & Body)** — один из лучших современных гротесков для цифровых экранов.
   - *Где используется*: Заголовки разделов (H2-H4), меню, кнопки, основной текст, формы.
   - *Роль*: Обеспечивает идеальную разборчивость, лаконичность и технологический минимализм.
3. **JetBrains Mono (Data & Numbers)** — высокопроизводительный моноширинный шрифт.
   - *Где используется*: Финансовые показатели, цифры статистики, код, даты публикаций.
   - *Роль*: Демонстрирует абсолютную точность данных и строгость математических алгоритмов.

### Шрифтовой масштаб (Fluid Typography)
Мы используем адаптивный масштаб, рассчитывающийся через формулу `clamp()` в зависимости от ширины экрана пользователя:
- `Hero Headline`: `clamp(3.5rem, 7.5vw + 0.5rem, 7.5rem)`
- `H1 / Large`: `clamp(2.5rem, 4.5vw + 0.1rem, 4rem)`
- `H2 / Section`: `clamp(2rem, 3.5vw + 0.1rem, 3rem)`
- `H3 / Subtitle`: `clamp(1.5rem, 2.5vw + 0.1rem, 2rem)`
- `Body Large`: `clamp(1.25rem, 2vw + 0.1rem, 1.5rem)`
- `Body Normal`: `clamp(1rem, 1.6vw + 0.1rem, 1.125rem)`
- `Label / Small`: `clamp(0.875rem, 1.4vw + 0.1rem, 1rem)`

## 3. Сетка и Отступы (Layout Constraints)

Вся пространственная сетка основана на шаге в **4px**:
- `var(--space-1)`: 4px
- `var(--space-2)`: 8px
- `var(--space-3)`: 12px
- `var(--space-4)`: 16px (базовый шаг для внутренних отступов мобильных)
- `var(--space-6)`: 24px
- `var(--space-8)`: 32px (базовый шаг для внутренних отступов десктопа)
- `var(--space-12)`: 48px
- `var(--space-16)`: 64px

### Правила секционных отступов (Section Rhythm)
Вертикальные отступы между крупными секциями на странице рассчитываются адаптивно:
`padding-top / padding-bottom: clamp(80px, 8vw + 10px, 160px)`.
Это гарантирует, что на мобильных устройствах сайт останется компактным, а на огромных экранах будет выглядеть свободно и легко дышать.

## 4. Скругления и Тени (Radii & Shadows)

### Радиус скругления
Мы избегаем острых углов для карточек, чтобы интерфейс выглядел премиально, но сохраняем строгость:
- `radius-sm` (4px) — флажки, чекбоксы.
- `radius-md` (8px) — кнопки, поля ввода.
- `radius-lg` (16px) — стандартные карточки услуг и новостей.
- `radius-xl` (24px) — крупные модальные окна, блоки секций.
- `radius-pill` (9999px) — теги категорий, овальные кнопки.

### Тени и эффект объема
Сайт выполнен в темной теме, поэтому тени служат для мягкого отделения уровней глубины (Z-index) друг от друга:
- `shadow-sm`: Мягкое отделение мелких элементов.
- `shadow-md`: Базовое парение карточек над фоном.
- `shadow-gold`: Золотистый ореол вокруг кнопок с эффектом мягкого неонового свечения: `0 8px 32px rgba(201, 168, 76, 0.15)`.
- `shadow-green`: Изумрудное свечение для зеленых акцентов: `0 8px 32px rgba(26, 61, 43, 0.25)`.
