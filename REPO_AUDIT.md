# REPO_AUDIT — Анализ текущего репозитория ddcnb_site

---

## 1. Текущий технологический стек
В ходе аудита кодовой базы [ddcnb_site](file:///Users/namazbekbekzhanov/AntigravityProjects/ddcnb_site) была зафиксирована следующая архитектура:
*   **Ядро**: Next.js 16.2.6 (Turbopack), React 19.
*   **Стилизация**: Tailwind CSS v4, Vanilla CSS в `app/globals.css`.
*   **Анимации**: GSAP 3.15 + `@gsap/react` для синхронизированного скролла и параллакса, Framer Motion 12 для интерактивных компонентов, Anime.js 4.4.1 для кинетических счетчиков.
*   **3D Слой**: React Three Fiber, Three.js 0.184, `@react-three/drei` для рендеринга интерактивных сцен.
*   **Скролл-движок**: Lenis для мягкой прокрутки.
*   **Управление формами и валидация**: Zod + React Hook Form.

---

## 2. Что уже построено и работает
1.  **Инфраструктура скролла**: Создан провайдер `SmoothScroll.tsx` для централизованной синхронизации Lenis c тикером GSAP и сброса ScrollTrigger при переходах.
2.  **Структура главной страницы**: Построены разделы Hero, About, Services, Security, CTA.
3.  **WebGL-компоненты**: Рендеринг частиц в `HeroScene` и `SakaGeometry` интегрирован и работает стабильно.
4.  **UI-компоненты**:
    *   `GlassCard.tsx` с поддержкой 3D-наклона (Tilt) и Spotlight Border.
    *   `ShimmerButton.tsx` с мерцающим градиентом граней.
    *   `TextReveal.tsx` для скролл-анимации появления текста.

---

## 3. Что необходимо заменить / доработать под требования конкурса
В связи с переходом на **новую визуальную концепцию конкурса "Forest Green & Gold"** и строгие требования доступности и многоязычности (i18n), требуется провести следующие изменения:
1.  **Ребрендинг стилей**:
    *   Удалить синие градиенты и переменные (`--brand-blue`, `--brand-blue-light` и др.) из `app/globals.css`.
    *   Внедрить новую зелено-золотую палитру (Forest Green, Prestige Gold, Accent Yellow) в CSS-переменные.
2.  **Интеграция полноценного i18n (KZ / RU / EN)**:
    *   Текущие языковые кнопки декоративны. Необходимо настроить библиотеку `next-intl` для бесшовной локализации всего контента без перезагрузки страницы.
3.  **Анимации счетчиков статистики**:
    *   Интегрировать `NumberTicker` (или оптимизированные счетчики Anime.js) для анимирования числовых показателей при попадании в зону видимости.
4.  **Свежие 3D-сцены**:
    *   Заменить абстрактные синие частицы в `HeroScene` на парящую золотую пыль и сакральную сакскую геометрию на глубоком фоновом тумане цвета темного леса (`#1A3D2B`).
5.  **Добавление недостающих страниц и разделов**:
    *   Создать полноценные внутренние страницы: `/about` (О центре), `/services` (Услуги), `/digital` (Цифровой Тенге), `/security` (Безопасность), `/analytics` (Информер курсов), `/news` (Пресс-центр), `/careers` (Вакансии), `/contact` (Контакты с формой), `/faq` (Аккордеон), `404` (Ошибки).
